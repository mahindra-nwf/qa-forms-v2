Product file designs

Two ways to organise log sheets by product, shown on an iPad in landscape. Log sheet names below are examples from the sample folder; your new sheets would go in the same places.

How it works

  • QA starts a run: pick the product and production date.
  • Every log sheet for that run is filled inside it, so one run = one batch record.
  • The run shows what's done and what's missing, then QA reviews and closes it.

Best for

  • Audits and traceability: one place shows everything about a day's production of a product.
  • Making sure no log is forgotten before product ships.

How it works

  • Home shows one folder per product.
  • Open a product to see its log sheets and fill any of them; product details fill in automatically.
  • Each folder has its own history of that product's records.

Best for

  • Simple, familiar layout, like a filing cabinet with one drawer per product.
  • Logs filled at different times, not tied to a single production run.
